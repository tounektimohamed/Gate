## 📖 Overview

**Gate** is a TypeScript web application for managing camps and events.

## ✨ Features

- ✓ Event & camp management
- ✓ Responsive UI
- ✓ Firebase-ready

## 🛠️ Tech Stack

TypeScript, Vite, Firebase.

## 📁 Project Structure

```text
.
src
  components
    AdminDashboard.tsx
    CampLeaderDashboard.tsx
    DashboardStats.tsx
    GatekeeperDashboard.tsx
    Login.tsx
    UnitLeaderDashboard.tsx
```

## 🚀 Getting Started

```bash
git clone https://github.com/tounektimohamed/Gate.git
cd Gate
npm install
npm run dev
```

> Open the dev server URL printed in your terminal.
